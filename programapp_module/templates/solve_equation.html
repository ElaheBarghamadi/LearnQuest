ax + b = 0
فرمت مجاز: ax + b = 0 (a و b می‌توانند اعشاری یا منفی باشند)

جواب معادله

📚 حل معادله درجه یک
ax + b = 0 → x = -b/a
  • اگر a ≠ 0 → معادله یک جواب دارد: x = -b/a
  • اگر a = 0 و b = 0 → معادله به ازای همه xها برقرار است
  • اگر a = 0 و b ≠ 0 → معادله جواب ندارد
  • ضرایب می‌توانند اعشاری یا کسری باشند
